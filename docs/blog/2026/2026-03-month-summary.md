# 休息最重要

一个月又过去了，最近比较忙，感觉时间过得很快。3月份，几乎所有的科技新闻都跟大模型相关，不知道我是不是被信息茧房了。


## 张雪峰因心源性猝死抢救无效去世
3月24日，苏州峰学蔚来教育科技有限公司发布讣告称，张雪峰因突发疾病，经抢救无效不幸去世。
当天晚上我老婆在小红书上刷到了这个新闻，然后告诉了我。我的第一反应这是一个谣言，但是后来我也有点好奇，就打开小红书搜了一下，然后看到有人说是真的，张老师的社交账号的头像已经灰了。第二天看到新闻说张老师是中午在公司跑步后出现不适，被送往医院经全力抢救无效于下午3点50分不幸去世。
这件事对我最大的影响是，我有点不敢晚上下了班回家再运动运动了，从来没有觉得休息是这么重要的一件事。张老师四十多岁的年纪，虽然并不算老，但是和二十岁的年轻人比，身体也已经完全不一样了。


## 测试是新的护城河
这是阮一峰这个月某一期周刊的标题，说的是cloudflare一个工程师只用一周时间就用AI重新实现了Next.js，并且性能比原版更好。之所以能做到，主要原因是Next.js有完备的文档、庞大的社区文章、以及完整的测试用例。AI模拟的每一个API，只要能够通过原有的接口测试，就能确认百分百兼容。
AI时代，软件的测试用例变得比任何其他时候都更重要。之前看过有很多独立开发者分享自己的经验，其中总是提到一条，快速开发出可用的功能，不用太关注软件的测试用例，甚至可以不写测试用例。在AI时代之前，这个我觉得是合理的，因为那个时候主要的问题是代码写的慢，但是都是人写的，所以对代码非常了解。现在只要你想要，AI可以短时间内写出非常多的代码，多到人根本看不过来。这个时候，除了软件的框架设计的非常好之外，可能最能保证代码质量的方式就是完整的测试用例了。不知不觉中，可能很多事情已经完全变了，之前的经验可能已经不适用了。


## cli
另一个最近变化很大的事情是，很多大厂最近都在完善自己产品的cli，得益于OpenClaw等智能体，人们发现大模型直接使用cli是一个更合适的方式。不需要调用各种复杂的api，也不需给你的模型接入什么MCP server，一下回到了计算机时代最原始的操作方式。也许将来MCP server才是主流，也许不会，但是目前，cli是更方便的选择，因为从零搭建MCP server需要时间，但是各种软件的cli之前就有，只不过有些并不完善，比从零开始速度更快。


## Token中文名定了：词元
以后不会有人好奇和争论token的中文应该叫什么了。但是如果让我把，“这一次请求消耗了多少token”改成“消耗了多少词元”，我现在感觉还是有点别扭的，以后可能大部分人还是会用token这个单词。但是官方新闻中，有了一个合适的词代替token。
