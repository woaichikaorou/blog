## "50 AI Agents Running My Company" Is a Lie
上月看的一个视频的标题，Gumloop联合创始人Max Brodeur-Urbas的一个访谈。说实话，在看这个视频之前，我并不知道Gumloop这个公司，也从来没有听过Max Brodeur-Urbas这个人。但是他在视频里说的很多观点，让我有一种茅塞顿开的感觉。以下是几句视频中的原话，也是我非常赞同的观点。

I think that the value comes from when you apply AI to something you understand deeply. 

我认为价值来自于当你将AI应用到你深刻理解的领域时。

If you're using AI to do something you don't actually understand at all, oftentimes you're creating just uncertainty. 

如果你用AI来做某件事而你实际上完全不懂其中的原理，很多时候你只是在制造不确定性。

Like if you're using AI to code and you don't know how to code at all, you're making malware at the end of the day. Like it'll come back to bite you.

比如，如果你用AI来编程而你根本不会编程，到头来你就是在制作恶意软件，最终它会反噬你。
